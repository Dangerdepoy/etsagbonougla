## 2. Informations d'entreprise à valider par le propriétaire

| Point | État actuel dans le code | Action attendue du propriétaire |
|---|---|---|
| **URL LAMANO DESIGN** | Configurée vide `LAMANO_DESIGN_URL = ''` dans `script.js` ; aucun lien fictif injecté | Fournir l'URL officielle vérifiée du portfolio du concepteur. |
| **Identifiants légaux** | Mention "Informations à compléter par le propriétaire" dans `mentions_legales.html` | Fournir le numéro RCCM et le Compte Contribuable (CC) officiels. |
| **Domaine de messagerie** | Formulaire orienté WhatsApp direct ; mentions affichent `contact@ets-agbonougla.ci` | Confirmer si l'adresse email officielle est sous `@ets-agbonougla.ci` ou sous `@etsagbonougla.net` (nom de domaine du site). |
| **Spécifications techniques détaillées** | Épaisseur d'isolation (polyuréthane 60-80 mm), tôles toiture, charge admissible | Valider les fiches techniques exactes avant publication commerciale définitive. |
| **Propriété des photos** | Toutes les photos proviennent des dossiers du projet d'origine | Confirmer que l'intégralité des photos (1 à 64) sont bien la propriété exclusive d'ETS AGBONOUGLA. |
